# 底部导航、对话列表与角色库布局试验

日期：2026-09-17。状态：探索参考，尚未实现。

![对话列表布局概念图](conversation-list-concept.png)

## 本次讨论确定的方向

- 底部四个入口按「对话｜角色｜模型｜我的」排列。
- 对话页汇总所有角色的聊天记录，每场独立对话单独一项，不按角色折叠；点击直接续聊。
- 模型作为独立功能区域；预设管理入口归入「我的」，聊天内保留预设快捷入口。

## 角色库：保留两种视图

角色页提供「两列封面」与「单列名册」两种布局，默认两列，在页面顶部提供视图切换按钮，并记住用户上次的选择。这个偏好只影响角色页，对话页保持单列。

两种布局共用角色数据、搜索条件与排序，点击角色都进入同一个详情页；不是两套独立功能。概念图尚未画出视图切换按钮，实际实现时需与顶部搜索、导入入口一起安排。

### 两列封面

![两列角色卡布局概念图](character-grid-concept.png)

强调封面浏览。图片区域比例统一，名字和一行简介放在图片外；无图角色使用占位。顶部为角色标题、数量、搜索和导入入口，底栏选中「角色」。

### 单列名册

![单列角色名册布局概念图](character-list-concept.png)

强调角色身份与快速查找。每行展示头像、名字和一行简介，点击进入详情。图中头像与行高仍可压缩，最终尺寸留待实际布局验证。

## 图片的使用边界

这些 AI 生成图仅用于试验布局和信息层级，**没有确认纸质童话风或任一图的视觉处理为后续统一视觉风格**。配色、纸纹、字体、插画、装饰和控件造型均未定稿，不应以这些图约束其他页面。角色双视图是本次接受的功能方向，不代表已完成实现。

角色头像、名字、简介、故事标题和消息均为概念占位内容；角色简介的实际字段来源尚未确定，不应默认生成或编造。图中的搜索、故事标题及装饰文案不代表已实现；其中对话搜索、对话命名尚未作出新增决定。实际行高、摘要信息量和底栏尺寸仍需布局验证。

对话图保留的是修正透底观感后的版本，角色图保留两列与单列两个方案，供讨论参考，不作为应用运行时资源。本次存档不修改现有启动动画或界面实现。
