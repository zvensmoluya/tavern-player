# 会话性能改进记录

日期：2026-09-15。总体设计见[会话性能改造方案](performance-design.md)，原始探针基线见[调查记录](performance-study-20260914.md)。

## 已实施

- 网页正文按实际 display 文本复用 Markdown 分段；未变化的消息对象跳过行处理，reasoning、状态、候选页面身份仍独立更新。解析结果随消息行释放。
- 原生 `SafeMarkdownText` 在 Compose 中按 source 复用清洗/块解析，行内标记按原文复用。
- 消息事实比较和作者操作回复合并使用一次身份索引，消除逐条查找历史的二次复杂度。
- 顺序不变时原生增量包省略 order；纯草稿包不触发外壳 render。外壳直接向协调器发送变化字段和消息，不再把每个 delta 扩成全快照跨 iframe 发送。
- 作者协调器无待确认写入时仅深复制变化消息和字段。草稿更新保留历史数组，消息更新保留未变消息对象；输入对象与已提交 base/可见 state 继续隔离。候选/顺序变化先淘汰旧 owner，之后处理待确认写入。
- page/static/script 的原生启动配置不再保存/传输完整历史；仅 session 配置持有启动快照。其他页面通过同源协调器读取作者数据。
- 自动贴底在 animation frame 真正执行时再次检查阅读位置和焦点。
- Character Regex 和世界书关键词共享有界 Pattern LRU：最多 256 项、源码合计 512 Ki 字符；超过源码预算的单条模式正常执行但不缓存。键为展开/改写后源码与 flags，不缓存 Matcher、宏结果或事务。
- 可加和 token 计数器提供单条成本与请求开销。裁剪按原有优先级扣减成本，最后完整验证；非加和计数器保留原路径。1000 条历史的测试要求一次成本表计算、一次最终完整校验。

## 会话存储与事务

本日后续已接入 Room、旧 JSON 完整导入、统一 ConversationSession、独立草稿与显式版本、原始流日志、节流预览和最终业务事务。失败回滚与恢复边界见[会话存储与事务实现](conversation-storage.md)。ChatViewModel 不再持有第二份可写 record；列表只观察摘要，打字不再写整个历史或生成请求。Kotlin 网页草稿快照只替换 draft/revision 字段，不再展开消息历史。

## 流式渲染连续性

同日补充静态富文本原地更新：同一候选、同一段只保留一个 static 文档，内容在帧内清洗并修补 DOM，不再每次流式更新都创建 iframe。普通 Markdown 在原节点上更新，文本尾部通过 appendData 续写；未变的属性不覆盖用户操作后的表单/details 状态。未完整 HTML 标签、CSS/script 块和潜在页面围栏先缓冲，原始流与持久正文保持完整。

文字转富文本时保留旧文字，完整交互页面则保留占位到加载及测量完成；新静态页面首次显示前确认已应用最新预览。显示只做短暂淡入，遵从减少动态效果偏好。作者可执行页面仍在 COMPLETE 事务保存后启动，源码/候选变化先撤销旧页面身份，再执行新页面。同步修正视口缩小与晚到测量/scroll 交错时丢失贴底意图的问题。

`npm run build`、`npm test`（47 项通过）、`node --test --test-concurrency=1 test/browser/*.test.mjs`（18 项通过）已执行。新增浏览器断言证明连续 12 次富文本更新只创建一个静态页面，保留文档、输入内容/焦点/选区、details 展开和图片节点；普通正文续写不移除已显示节点。慢页面测试验证保留占位、后续消息继续渲染及静态页面追上最新内容。HTML 围栏按每个字符前缀检验，更新路径继续清洗脚本和事件属性。

最后的渲染定向回归 `node --test --test-concurrency=1 test/browser/render.test.mjs` 共 9 项通过，包含页面就绪通知先于消息渲染通知的顺序断言。

`node performance-probe.mjs` 保持原有不变量：各历史规模下草稿零次 Markdown 解析、20 次尾更新只解析变化消息 20 次。`.\gradlew.bat :app:assembleDebug --max-workers=2 --no-configuration-cache --no-daemon` 成功；APK 内 13 项网页资源与当前构建及 manifest 一致。本轮仅改网页运行时，未重复执行无关 Kotlin 单测或 lint。

回归中发现高度动画会干扰贴底，最终实现已移除高度动画；另以固定事件交错复现并修复键盘视口与迟到滚动通知的竞争。当前仍完整解析变化消息的 Markdown，静态更新仍传递及清洗当前段全文；新 CSS、图片尺寸及交互页面最终布局仍可能引起重排，不宣称任意 HTML 都能逐字显示或完全没有卡顿。具体边界见[网页运行契约](web-runtime.md)。本轮 `adb devices` 无连接设备，未运行 Android WebView 真机键盘/滚动、上屏耗时或内存验收。

## 尚未替换的边界

活动会话仍在内存中持有完整领域记录和诊断，打开时只加载该会话；分页读取 API 已提供，但聊天 UI 尚未使用数据库有界窗口。正文变化时仍会构造原生快照后差分，作者有待确认写入时仍保守重建可见视图，作者操作回复仍可携带全快照。EJS 挂起续行、展示队列合并、资源取得优化、按引用分批回收和所有工作量有界尚未完成；当前孤立内容在生成结束后的空闲时段进行数据库引用扫描回收。
